# Security reporting

For a suspected vulnerability or accidentally exposed credential, contact the maintainer privately at [ksuyamburaj07@gmail.com](mailto:ksuyamburaj07@gmail.com). Include affected source/version, a minimal reproduction, and the likely impact. Do not include live credentials or private image/model/report files in a public issue.

This is a research prototype without a guaranteed response time or supported enterprise release schedule. Software checks and the public-release audit do not establish industrial certification or comprehensive security assurance.
